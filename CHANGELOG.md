# Changelog

## 1.0.0 (unreleased)

The first open-source release of the 1FounderTool method as portable agent skills.

- Nine skills covering the whole journey: app-builder (start here and resume),
  app-idea, app-plan, app-design, app-build, app-change, app-fix, app-review
  and app-launch.
- Project memory in plain Markdown (`product/`), so work continues across
  sessions and across AI tools.
- Talks in the person's language, and builds in their customers' language;
  tone notes for 20 languages.
- Ten feature guides: sign-in, payments, email, file uploads, scheduled
  jobs, multiple languages, landing page, search and sharing, spreadsheet
  data, feature switches. Each runs in test mode locally, with no accounts
  needed.
- `quality-scan.mjs`: a dependency-free scan for leaked secrets, unsafe
  HTML, placeholder text and stray colours.
- Installers: `npx`, `install.sh`, `install.ps1`, a Claude Code plugin
  marketplace, a Codex plugin marketplace, a Gemini CLI extension,
  Claude Desktop zips and a single-file prompt for chat assistants.
