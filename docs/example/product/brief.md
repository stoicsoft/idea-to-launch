# The idea

**Building:** A booking page where Mai's regulars pick a free time without messaging her.
**Confirmed:** 2026-10-26: "Yes, that's it"

| | |
|---|---|
| **The problem** | Regulars message Mai on Zalo to book; she answers between clients and sometimes double-books. |
| **Who** | Linh, a regular who books every 3 weeks; Mai, the owner. |
| **Today** | Zalo messages and a paper diary. |
| **What it costs** | About 40 minutes a day replying; 1–2 double bookings a month. |
| **The moment** | Friday evening, planning the weekend. |
| **Smallest useful version** | Regulars see free times this week and book one, and Mai sees the list. |
| **How we'll know** | 10 bookings through the page in the first two weeks, and no double bookings. |
| **Constraints** | Customers read Vietnamese; prices in VND; works on old Android phones. |
| **Where you are** | People already do this somehow. |

## Not in this version
- Online payment: regulars pay in the salon; no reason to add it yet.
- Reminders by message: useful, but the booking page comes first.

## What they'd use instead
- Zalo: instant and familiar. The page has to be faster than a message.

## Riskiest guess
- I think regulars will use a link instead of messaging. Check: put the link in Mai's Zalo auto-reply for two weeks.
