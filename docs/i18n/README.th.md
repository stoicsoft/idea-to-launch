# Idea to Launch

**เปลี่ยนไอเดียของคุณให้เป็นซอฟต์แวร์ที่ใช้งานได้จริง โดยไม่ต้องเรียนเขียนโค้ด**

Idea to Launch คือชุดสกิลฟรีสำหรับผู้ช่วย AI ที่คุณใช้อยู่แล้ว ทั้ง Claude, Codex, Cursor, Gemini, GitHub Copilot และ[เครื่องมืออื่นอีก 15 ตัว](../install.md#every-supported-tool) แค่เล่าไอเดียด้วยคำพูดของคุณเอง เป็นภาษาของคุณเอง ผู้ช่วยจะถามคำถามสำคัญสักไม่กี่ข้อ เขียนแผนหนึ่งหน้าให้คุณอนุมัติ ลงมือสร้าง ตรวจดูแบบที่ลูกค้าจริงใช้งาน และช่วยคุณนำขึ้นอินเทอร์เน็ต

## ใช้งานจริงเป็นแบบไหน

> **คุณ:** เปิดร้านทำเล็บเล็ก ๆ อยู่ ลูกค้าประจำชอบทักแชตมาจองคิว แล้วก็จำไม่ไหวว่าใครจองตอนไหน ช่วยทำอะไรสักอย่างให้หน่อยได้ไหม
>
> **ผู้ช่วย:** ได้เลย ขอถามสั้น ๆ สักสองสามข้อก่อน จะได้สร้างให้ตรงกับที่ต้องการ **1. ใครจองบ่อยที่สุด** a) ลูกค้าประจำที่รู้จักคุณอยู่แล้ว (แนะนำ) · b) ลูกค้าใหม่ที่เจอร้านทางออนไลน์ · …

คุยกันอีกไม่กี่รอบ คุณก็จะได้:
- **สรุปไอเดียหนึ่งหน้า** ด้วยคำพูดของคุณเอง เช่น “หน้าจองคิวที่ลูกค้าประจำของ Mai เลือกเวลาว่างได้เอง โดยไม่ต้องทักแชตมาหา”
- **แผนที่คุณอนุมัติ** ก่อนจะเริ่มสร้างอะไรทั้งนั้น
- **หน้าตาที่คุณเลือกเอง** จากสามแบบ
- **แอปที่ใช้งานได้จริง** เปิดลองใช้ได้ทันที มีข้อมูลตัวอย่างที่ดูสมจริง และเป็นภาษาที่ลูกค้าของคุณใช้
- **การตรวจแบบตรงไปตรงมา** จากมุมมองของวิศวกรมากประสบการณ์ และลูกค้าที่เพิ่งเข้ามาใช้ครั้งแรกบนมือถือ
- **ความช่วยเหลือทีละขั้นตอนจนเปิดใช้งานจริง** บนที่อยู่เว็บของคุณเอง และจะไม่มีอะไรขึ้นออนไลน์ เสียเงิน หรือไปถึงลูกค้าจริง จนกว่าคุณจะตอบ “ตกลง” อย่างชัดเจน

## ติดตั้ง

คัดลอกคำสั่งบรรทัดเดียวไปวางในเทอร์มินัลของคอมพิวเตอร์ คำสั่งนี้จะค้นหาเครื่องมือ AI ในคอมพิวเตอร์ของคุณ (Claude Code, Codex, Cursor, Gemini CLI, Copilot และ[อีก 15 ตัว](../install.md#every-supported-tool)) แล้วติดตั้งสกิลให้ครบทุกตัว คำสั่งนี้แค่คัดลอกไฟล์ข้อความ ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ และคุณถอนการติดตั้งได้ทุกเมื่อ

**บน Mac** (หรือ Linux): กด ⌘ Space พิมพ์ `Terminal` แล้วกด Enter เพื่อเปิด **Terminal** (เทอร์มินัล) จากนั้นวางบรรทัดนี้ลงไป แล้วกด Enter:

```sh
curl -fsSL https://raw.githubusercontent.com/stoicsoft/idea-to-launch/main/install.sh | bash
```

**บน Windows:** กดปุ่ม Windows พิมพ์ `PowerShell` แล้วกด Enter เพื่อเปิด **PowerShell** จากนั้นวางบรรทัดนี้ลงไป แล้วกด Enter:

```powershell
irm https://raw.githubusercontent.com/stoicsoft/idea-to-launch/main/install.ps1 | iex
```

จากนั้น**รีสตาร์ตเครื่องมือ AI ของคุณ** (หรือเริ่มแชตใหม่) แล้วพิมพ์ว่า:

> อยากสร้างแอปสำหรับธุรกิจของตัวเอง ช่วยหน่อยได้ไหม

ถ้าคุณใช้ Node.js อยู่แล้ว คำสั่ง `npx github:stoicsoft/idea-to-launch` ก็ทำแบบเดียวกันได้

### วิธีติดตั้งแบบอื่น

| เครื่องมือของคุณ | วิธีติดตั้ง |
|---|---|
| **Claude Code** แบบปลั๊กอิน | `/plugin marketplace add stoicsoft/idea-to-launch` จากนั้น `/plugin install idea-to-launch@idea-to-launch` |
| **Codex** (แอปหรือแบบพิมพ์คำสั่ง) แบบปลั๊กอิน | `codex plugin marketplace add stoicsoft/idea-to-launch` จากนั้น `codex plugin add idea-to-launch@idea-to-launch` |
| **Gemini CLI** แบบส่วนขยาย | `gemini extensions install https://github.com/stoicsoft/idea-to-launch` |
| **Claude Desktop** (แชต) หรือ claude.ai | คำสั่งด้านบนติดตั้งให้สองที่นี้ไม่ได้ ดาวน์โหลดไฟล์ zip จาก [Releases](https://github.com/stoicsoft/idea-to-launch/releases) (หน้ารวมเวอร์ชันที่เผยแพร่) แล้วอัปโหลดทีละไฟล์ที่ **Settings → Capabilities → Skills → Upload skill** (การตั้งค่า → ความสามารถ → สกิล → อัปโหลดสกิล) ([ดูรายละเอียด](../install.md#claude-desktop-and-claudeai)) |
| **ChatGPT หรือผู้ช่วยแชตอื่น ๆ** | อัปโหลด [`idea-to-launch-prompt.md`](../install.md#chatgpt-and-other-chat-assistants) ไปไว้ในโปรเจกต์หรือ GPT ที่สร้างเอง |

ดูคู่มือฉบับเต็มได้ที่ [docs/install.md](../install.md) มีครบทุกเครื่องมือ วิธีเลือกว่าจะติดตั้งสกิลให้เครื่องมือไหนบ้าง รวมถึงวิธีอัปเดตหรือถอนการติดตั้ง

## ขั้นตอน

คุณไม่จำเป็นต้องเรียกชื่อขั้นตอนเหล่านี้เลย แค่บอกว่าอยากได้อะไร ผู้ช่วยจะเลือกขั้นตอนที่เหมาะให้เอง ถ้าอยากเรียกขั้นตอนเองก็ทำได้ เช่น พิมพ์ `/app-idea` ใน Claude Code หรือ Cursor

| ขั้นตอน | สิ่งที่เกิดขึ้น | ลองพูดว่า |
|---|---|---|
| **app-builder** | เริ่มที่นี่ ดูว่าคุณต้องการอะไร และทำต่อจากที่ค้างไว้ | “ช่วยสร้างแอปหน่อย” · “ทำต่อเลย” |
| **app-idea** | สัมภาษณ์สั้น ๆ ว่าทำให้ใครใช้ และเวอร์ชันเล็กที่สุดที่ยังมีประโยชน์หน้าตาเป็นอย่างไร แล้วบันทึกเป็นสรุปหนึ่งหน้า | “มีไอเดียว่า…” |
| **app-plan** | แต่ละคนจะทำอะไรได้บ้าง รายละเอียดงานหนึ่งหน้า และแผนที่คุณอนุมัติ | “แผนเป็นยังไงบ้าง” |
| **app-design** | มีหน้าตาให้เลือกสามแบบ แล้วจัดให้เป็นสไตล์เดียวกันทั้งหมด | “ควรออกมาหน้าตาแบบไหน” |
| **app-build** | สร้างทีละขั้น ตามลำดับที่คุณจะเห็นมันเริ่มใช้งานได้ | “สร้างเลย” · “เพิ่มหน้าจองคิว” |
| **app-change** | แก้เล็ก ๆ น้อย ๆ ให้จบในข้อความเดียว หรือเปลี่ยน “นี่ไม่ใช่แบบที่อยากได้” ให้เป็นรายการสิ่งที่ต้องแก้ | “เปลี่ยนปุ่มเป็นสีเขียว” |
| **app-fix** | หาสาเหตุที่แท้จริงของปัญหา แล้วแก้เฉพาะจุดนั้น | “พอ… แล้วขึ้นข้อผิดพลาด” |
| **app-review** | ตรวจแบบวิศวกร และแบบลูกค้าที่เพิ่งมาใช้ครั้งแรก | “พร้อมให้ลูกค้าใช้หรือยัง” |
| **app-launch** | นำขึ้นออนไลน์อย่างปลอดภัย โดยขอความเห็นชอบจากคุณทุกครั้งก่อนทำขั้นตอนที่ย้อนกลับไม่ได้ | “เอาขึ้นออนไลน์เลย” |

## โปรเจกต์ของคุณจำได้เสมอ

ทุกอย่างที่สำคัญจะถูกบันทึกเป็นหน้าเอกสารง่าย ๆ ในโฟลเดอร์ `product/` ภายในโปรเจกต์ของคุณ ได้แก่ สรุปไอเดีย แผน หน้าตา สิ่งที่ตัดสินใจไปแล้ว ผลการตรวจ และขั้นตอนถัดไป จะปิดแชต กลับมาอีกทีสัปดาห์หน้า หรือเปลี่ยนจาก Claude ไปใช้ Codex ผู้ช่วยก็ทำต่อจากที่คุณค้างไว้ได้ ส่วนแอปที่แชตได้อย่างเดียว ผู้ช่วยจะส่งหน้าเหล่านี้ให้คุณเก็บไว้เองแทน

## ภาษาของคุณ

- ผู้ช่วย**คุยกับคุณเป็นภาษาของคุณ** คุณพิมพ์มาเป็นภาษาอะไร ก็ตอบเป็นภาษานั้น
- แอปใช้**ภาษาของลูกค้าคุณ** ซึ่งอาจต่างจากภาษาของคุณ หรือมีหลายภาษาพร้อมกันก็ได้
- โค้ดยังเป็นภาษาอังกฤษ นักพัฒนาคนไหนก็มารับช่วงต่อได้ในภายหลัง

ผ่านการทดสอบแล้วใน 20 ภาษา ได้แก่ English, 简体中文, 繁體中文, Español, हिन्दी, العربية, Português, Français, Русский, 日本語, Deutsch, Bahasa Indonesia, Tiếng Việt, 한국어, Türkçe, Italiano, ไทย, Polski, Nederlands และ Українська ภาษาอื่นส่วนใหญ่ก็ใช้ได้เช่นกัน

## สิ่งที่สัญญาไว้

- **ใช้คำง่าย ๆ** ไม่มีศัพท์เฉพาะ คำทางเทคนิคจะอธิบายแค่ครั้งเดียว ตอนที่ต้องใช้ครั้งแรก
- **เรื่องสำคัญ คุณเป็นคนตัดสินใจ** อะไรที่ย้อนกลับยาก (การลบข้อมูล การกำหนดว่าใครเห็นอะไรได้บ้าง การชำระเงิน การส่งอีเมลถึงลูกค้า และการขึ้นออนไลน์) จะรอคำตอบที่ชัดเจนจากคุณเสมอ ส่วนเรื่องเล็ก ๆ ที่ย้อนกลับได้ ผู้ช่วยจะตัดสินใจให้ คุณจะได้ไม่ต้องจมอยู่กับคำถาม
- **ผลลัพธ์ที่ตรงไปตรงมา** จะบอกว่าใช้ได้ก็ต่อเมื่อได้ลองจริงแล้วเท่านั้น และบอกด้วยว่ามีอะไรที่ยังตรวจไม่ได้
- **ดูแลข้อมูลลูกค้าของคุณอย่างปลอดภัย** เป็นส่วนตัวตั้งแต่แรก การแก้ไขจะไม่ลบข้อมูลที่บันทึกไว้ และข้อมูลลับอย่างรหัสผ่านจะไม่ถูกใส่ไว้ในโค้ด
- **เป็นของคุณ** โค้ดมาตรฐานที่อ่านเข้าใจได้ และบันทึกเป็นข้อความธรรมดา ไม่ผูกมัดคุณไว้กับบริการใด ไม่ต้องมีบัญชี และไม่มีการติดตามการใช้งาน

## ควรรู้ไว้

- การสร้างแอปจริงต้องใช้เครื่องมือที่ทำงานกับไฟล์ในคอมพิวเตอร์ของคุณได้ เช่น Claude Code (หรือแท็บ Code ใน Claude Desktop), Codex, Cursor, Gemini CLI, Copilot และเครื่องมือคล้าย ๆ กัน แอปที่แชตได้อย่างเดียวช่วยวางแผน และทำต้นแบบที่กดลองใช้ได้
- แพ็กเกจและขีดจำกัดการใช้งานปกติของเครื่องมือ AI ของคุณยังมีผลตามเดิม เมื่อเปิดใช้งานจริงแล้ว ค่าโฮสติ้งและชื่อโดเมนมักอยู่ที่ไม่กี่ดอลลาร์ต่อเดือน ผู้ช่วยจะบอกคุณก่อนเสมอถ้ามีอะไรต้องเสียเงิน
- นี่คือผู้ช่วยที่รอบคอบ แต่ไม่ใช่ทนายความหรือนักบัญชี เรื่องการชำระเงิน ข้อมูลสุขภาพ หรืออะไรก็ตามที่มีกฎหมายควบคุม ผู้ช่วยจะบอกว่าเมื่อไรที่คุณควรปรึกษาผู้เชี่ยวชาญ
