# Software Builder

**Превратите свою идею в работающую программу — учиться программировать не придётся.**

Software Builder — это бесплатный набор навыков для ИИ-ассистента, которым вы
уже пользуетесь: Claude, Codex, Cursor, Gemini, GitHub Copilot и
[ещё 15 инструментов](../install.md#every-supported-tool). Опишите идею своими
словами и на своём языке. Ассистент задаст несколько толковых вопросов,
напишет план на одну страницу вам на утверждение, создаст приложение, проверит
его так, как это сделал бы настоящий клиент, и поможет выложить его в интернет.

**Языки:** [English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Português](README.pt-BR.md) · [Français](README.fr.md) · **Русский** · [日本語](README.ja.md) · [Deutsch](README.de.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md) · [한국어](README.ko.md) · [Türkçe](README.tr.md) · [Italiano](README.it.md) · [ไทย](README.th.md) · [Polski](README.pl.md) · [Nederlands](README.nl.md) · [Українська](README.uk.md)

## Как это выглядит

> **Вы:** У меня небольшой маникюрный салон. Постоянные клиенты записываются
> через переписку, и я вечно путаюсь, кто когда. Можно для этого что-нибудь
> сделать?
>
> **Ассистент:** Да. Сначала пара коротких вопросов, чтобы сделать именно то,
> что нужно. **1. Кто записывается чаще всего?** а) Постоянные клиенты, которые
> вас уже знают (рекомендую) · б) Новые клиенты, которые находят вас в
> интернете · …

Ещё несколько раундов — и у вас есть:
- **описание идеи на одну страницу**, вашими словами: «Страница записи, где
  постоянные клиенты Оли сами выбирают свободное окошко — без переписки с ней»;
- **план, который вы утверждаете** до того, как что-то начнут делать;
- **внешний вид, выбранный вами** из трёх вариантов;
- **работающее приложение**, которое можно открыть и попробовать, с
  правдоподобными примерами данных на языке ваших клиентов;
- **честная проверка** глазами опытного разработчика и клиента, который
  впервые открыл приложение на телефоне;
- **пошаговая помощь с запуском** на вашем собственном адресе — и ничего не
  появится в интернете, не будет стоить денег и не затронет настоящих клиентов
  без вашего чёткого «да».

## Установка

Выберите инструмент, которым пользуетесь. Любой вариант устанавливает одни и те
же навыки.

| Ваш инструмент | Как установить |
|---|---|
| **Любой инструмент, одна команда** (нужен [Node.js](https://nodejs.org)) | `npx github:OWNER/REPO` находит ваши ИИ-инструменты и устанавливает навыки во все сразу |
| **Mac или Linux без Node.js** | `curl -fsSL https://raw.githubusercontent.com/OWNER/REPO/main/install.sh \| bash` |
| **Windows** (PowerShell) | `irm https://raw.githubusercontent.com/OWNER/REPO/main/install.ps1 \| iex` |
| **Claude Code** | `/plugin marketplace add OWNER/REPO`, затем `/plugin install software-builder@software-builder` |
| **Claude Desktop** (чат) или claude.ai | Скачайте zip-архивы со страницы [Releases](https://github.com/OWNER/REPO/releases), затем загрузите каждый через **Settings → Capabilities → Skills → Upload skill** («Настройки → Возможности → Навыки → Загрузить навык»; [подробнее](../install.md#claude-desktop-and-claudeai)) |
| **Codex** (приложение или командная строка) | `codex plugin marketplace add OWNER/REPO`, затем `codex plugin add software-builder@software-builder` |
| **Cursor, Gemini CLI, Copilot, Windsurf, OpenCode, Kiro…** | Установка одной командой (см. выше) или [инструкции для каждого инструмента](../install.md) |
| **ChatGPT или любой другой чат-ассистент** | Загрузите [`software-builder-prompt.md`](../install.md#chatgpt-and-other-chat-assistants) в проект или в свой GPT (custom GPT) |

Затем **перезапустите свой ИИ-инструмент** (или начните новый чат) и напишите:

> Хочу сделать приложение для своего бизнеса. Можешь помочь?

Полное руководство — со всеми инструментами, а также о том, как обновить или
удалить навыки, — в [docs/install.md](../install.md).

## Шаги

Вызывать их по имени не обязательно. Просто скажите, чего хотите, и ассистент
сам выберет нужный шаг. Если вам так удобнее, шаг можно вызвать напрямую —
например, `/app-idea` в Claude Code или Cursor.

| Шаг | Что происходит | Что можно сказать |
|---|---|---|
| **app-builder** | Начните отсюда. Разбирается, что вам нужно, и продолжает с того места, где вы остановились | «Помоги сделать приложение» · «Продолжим» |
| **app-idea** | Короткая беседа о том, для кого это и какой может быть самая маленькая полезная версия; итог — описание идеи на одну страницу | «У меня есть идея…» |
| **app-plan** | Что сможет делать каждый человек, описание приложения на одну страницу и план, который вы утверждаете | «Какой у нас план?» |
| **app-design** | Три варианта внешнего вида на выбор, а затем единый стиль | «Как это должно выглядеть?» |
| **app-build** | Создаёт приложение шаг за шагом, в том порядке, в котором вы увидите, как оно заработает | «Давай делать» · «Добавь страницу записи» |
| **app-change** | Небольшие правки одним сообщением, или «это совсем не то, что нужно» превращается в список исправлений | «Сделай кнопку зелёной» |
| **app-fix** | Находит настоящую причину проблемы и исправляет только её | «Выскакивает ошибка, когда я…» |
| **app-review** | Проверяет приложение глазами разработчика и клиента, который открыл его впервые | «Уже можно показывать клиентам?» |
| **app-launch** | Аккуратно выкладывает приложение в интернет и спрашивает вашего согласия перед каждым шагом, который нельзя отменить | «Выложи в интернет» |

## Проект всё помнит

Всё важное сохраняется в виде простых страниц в папке `product/` внутри вашего
проекта: описание идеи, план, внешний вид, принятые решения, результаты
проверок и следующий шаг. Закройте чат, вернитесь через неделю или перейдите с
Claude на Codex — ассистент продолжит с того места, где вы остановились. В
приложениях, где есть только чат, он вместо этого отдаёт эти страницы вам на
хранение.

## Ваш язык

- Ассистент **говорит с вами на вашем языке** — на том, на котором вы пишете.
- Приложение говорит **на языке ваших клиентов**: он может отличаться от
  вашего, а может быть и несколько языков сразу.
- Сам код остаётся на английском, чтобы позже его мог подхватить любой
  разработчик.

Software Builder проверен на 20 языках: English, 简体中文, 繁體中文, Español, हिन्दी,
العربية, Português, Français, Русский, 日本語, Deutsch, Bahasa Indonesia,
Tiếng Việt, 한국어, Türkçe, Italiano, ไทย, Polski, Nederlands и
Українська. С другими языками обычно тоже всё работает.

## Обещания, которые он выполняет

- **Простые слова.** Никакого жаргона. Технические слова объясняются один раз —
  когда они впервые понадобятся.
- **Важное решаете вы.** Всё, что трудно отменить (удаление данных, кто что
  может видеть, платежи, письма клиентам, выход в интернет), всегда ждёт вашего
  прямого ответа. Мелочи, которые легко отменить, решаются за вас, чтобы вас не
  завалило вопросами.
- **Честные результаты.** Он говорит, что что-то работает, только после
  настоящей проверки и честно сообщает, что проверить не получилось.
- **Бережно к данным ваших клиентов.** По умолчанию всё закрыто от
  посторонних, изменения никогда не удаляют сохранённую информацию, а пароли и
  ключи доступа не хранятся в коде.
- **Всё ваше.** Стандартный, понятный код и заметки обычным текстом. Никакой
  привязки к сервису, никаких аккаунтов, никакой слежки.

## Полезно знать

- Чтобы сделать настоящее приложение, нужен инструмент, который умеет работать
  с файлами на вашем компьютере: Claude Code (или вкладка Code в Claude
  Desktop), Codex, Cursor, Gemini CLI, Copilot и похожие. Приложения, где есть
  только чат, помогут с планированием и прототипом, по которому можно
  покликать.
- Действуют обычный тариф и лимиты вашего ИИ-инструмента. После запуска хостинг
  и собственный домен (адрес сайта) обычно стоят несколько долларов в месяц.
  Ассистент предупредит заранее, прежде чем что-то начнёт стоить денег.
- Это внимательный помощник, а не юрист и не бухгалтер. Если речь о платежах,
  медицинских данных или о чём-то, что регулирует закон, он скажет, когда нужен
  специалист.
