# Software Builder

**プログラミングを覚えなくても、アイデアを実際に使えるソフトウェアに。**

Software Builder は、いつも使っている AI アシスタントに追加できる無料のスキル集です。Claude、Codex、Cursor、Gemini、GitHub Copilot のほか、[さらに15種類のツール](../install.md#every-supported-tool)で使えます。アイデアは、ふだんの言葉で、ふだん使っている言語のまま伝えてください。アシスタントがいくつか大事な質問をして、1ページの計画を書いて確認をお願いし、実際に作り、本物のお客さんになったつもりでチェックして、インターネットに公開するところまで手伝います。

**言語：** [English](../../README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [Español](README.es.md) · [हिन्दी](README.hi.md) · [العربية](README.ar.md) · [Português](README.pt-BR.md) · [Français](README.fr.md) · [Русский](README.ru.md) · **日本語** · [Deutsch](README.de.md) · [Bahasa Indonesia](README.id.md) · [Tiếng Việt](README.vi.md) · [한국어](README.ko.md) · [Türkçe](README.tr.md) · [Italiano](README.it.md) · [ไทย](README.th.md) · [Polski](README.pl.md) · [Nederlands](README.nl.md) · [Українська](README.uk.md)

## 使ってみるとこんな感じです

> **あなた：** 小さなネイルサロンをやっています。常連さんはメッセージで予約してくるのですが、だれがいつなのか分からなくなってしまって。何かいい仕組みを作ってもらえますか？
>
> **アシスタント：** はい、作れます。ぴったりのものを作るために、まず簡単な質問をいくつかさせてください。**1. いちばんよく予約するのはどなたですか？** a) すでにお店をよく知っている常連さん（おすすめ） · b) ネットで見つけてくれた新しいお客さん · …

何度かやりとりすると、こんなものがそろいます。
- **アイデアを1ページにまとめた概要**：あなた自身の言葉でまとめます。たとえば「Mai さんの常連さんが、メッセージを送らなくても空いている時間を自分で選べる予約ページ」
- **あなたが承認する計画**：承認するまで、何も作り始めません。
- **自分で選んだデザイン**：3つの案から選べます。
- **実際に開いて試せるアプリ**：本物らしいサンプル内容が入っていて、お客さんが使う言語で表示されます。
- **正直なチェック結果**：経験豊富なエンジニアの目線と、スマホで初めて使うお客さんの目線の両方から確認します。
- **公開までの手順を一つずつサポート**：独自のアドレスで公開できます。あなたがはっきり「はい」と言わない限り、勝手に公開したり、お金がかかったり、本物のお客さんに影響したりすることはありません。

## インストール

お使いのツールを選んでください。どの方法でも、入るスキルは同じです。

| お使いのツール | インストール方法 |
|---|---|
| **どのツールでも、コマンド1つで**（[Node.js](https://nodejs.org) が必要） | `npx github:OWNER/REPO` が AI ツールを見つけて、そのすべてにインストールします |
| **Mac または Linux（Node.js なし）** | `curl -fsSL https://raw.githubusercontent.com/OWNER/REPO/main/install.sh \| bash` |
| **Windows**（PowerShell） | `irm https://raw.githubusercontent.com/OWNER/REPO/main/install.ps1 \| iex` |
| **Claude Code** | `/plugin marketplace add OWNER/REPO` のあと、`/plugin install software-builder@software-builder` |
| **Claude Desktop**（チャット）または claude.ai | [Releases](https://github.com/OWNER/REPO/releases)（公開版のページ）から zip ファイルをダウンロードし、1つずつ **Settings → Capabilities → Skills → Upload skill**（設定 → 機能 → スキル → スキルをアップロード）からアップロードします（[詳しくはこちら](../install.md#claude-desktop-and-claudeai)） |
| **Codex**（アプリ版またはコマンドライン版） | `codex plugin marketplace add OWNER/REPO` のあと、`codex plugin add software-builder@software-builder` |
| **Cursor、Gemini CLI、Copilot、Windsurf、OpenCode、Kiro…** | 上の「コマンド1つ」の方法を使うか、[すべてのツール](../install.md)を見てください |
| **ChatGPT やその他のチャットアシスタント** | [`software-builder-prompt.md`](../install.md#chatgpt-and-other-chat-assistants) をプロジェクトまたはカスタム GPT にアップロードします |

そのあと **AI ツールを再起動**（または新しいチャットを開始）して、こう話しかけてください。

> 自分のビジネスのためにアプリを作りたいです。手伝ってもらえますか？

すべてのツールの手順や、アップデート・削除の方法を含む完全なガイドは [docs/install.md](../install.md) にあります。

## ステップ

ステップの名前を覚える必要はありません。やりたいことをそのまま伝えれば、アシスタントが合ったステップを選びます。直接呼び出したいときは、たとえば Claude Code や Cursor で `/app-idea` と入力します。

| ステップ | すること | こんなふうに話しかけます |
|---|---|---|
| **app-builder** | まずはここから。何が必要かを整理し、前回の続きから再開します | 「アプリ作りを手伝ってください」 · 「続きをお願いします」 |
| **app-idea** | 誰のためのものか、いちばん小さくても役に立つ形は何かを短いインタビューで確かめ、1ページの概要にまとめます | 「こんなアイデアがあって…」 |
| **app-plan** | それぞれの人が何をできるようになるか、1ページの仕様書、そしてあなたが承認する計画 | 「どんな計画になりますか？」 |
| **app-design** | 3つのデザインから選んでもらい、そのあと統一感のあるスタイルに整えます | 「見た目はどうしましょう？」 |
| **app-build** | 動いていく様子が見える順番で、一歩ずつ作ります | 「作ってください」 · 「予約ページを追加してください」 |
| **app-change** | メッセージ1つで済む小さな変更や、「思っていたのと違う」を修正リストにまとめます | 「ボタンを緑にしてください」 |
| **app-fix** | 問題の本当の原因を見つけて、そこだけを直します | 「…するとエラーが出ます」 |
| **app-review** | エンジニアの目線と、初めて使うお客さんの目線の両方でチェックします | 「お客さんに使ってもらっても大丈夫ですか？」 |
| **app-launch** | 取り消せない操作のたびにあなたの承認をもらいながら、安全に公開します | 「公開してください」 |

## プロジェクトが覚えています

大事なことはすべて、プロジェクト内の `product/` フォルダにシンプルなページとして保存されます。概要、計画、デザイン、決めたこと、チェック結果、そして次のステップです。チャットを閉じても、翌週に戻ってきても、Claude から Codex に乗り換えても、アシスタントは前回の続きから再開します。チャットだけのアプリでは、代わりにこれらのページを手元に保存できるようお渡しします。

## 言語について

- アシスタントは**あなたの言語で話します**。書いた言語で、そのまま返事をします。
- アプリは**お客さんの言語**で表示されます。あなたの言語と違っていても、複数の言語を同時に使っても大丈夫です。
- コードは英語のままなので、あとからどんな開発者でも引き継げます。

English、简体中文、繁體中文、Español、हिन्दी、العربية、Português、Français、Русский、日本語、Deutsch、Bahasa Indonesia、Tiếng Việt、한국어、Türkçe、Italiano、ไทย、Polski、Nederlands、Українська の20言語でテストしています。それ以外の言語でも、たいていは問題なく使えます。

## 約束していること

- **わかりやすい言葉で。** 専門用語は使いません。技術的な言葉は、初めて必要になったときに一度だけ説明します。
- **大事なことはあなたが決めます。** 元に戻しにくいこと（データの削除、誰に何を見せるか、支払い、お客さんへのメール、公開）は、必ずあなたのはっきりした返事を待ちます。小さくて元に戻せることはこちらで決めるので、質問攻めになることはありません。
- **結果は正直に。** 実際に試してからでないと「動きます」とは言いません。確認できなかったことも、きちんと伝えます。
- **お客さんのデータを安全に。** 最初から非公開が基本です。保存済みの情報を消すような変更はせず、パスワードなどの秘密の情報はコードに書き込みません。
- **作ったものはあなたのもの。** 標準的で読みやすいコードと、シンプルなテキストのメモです。特定のサービスに縛られることも、アカウント登録も、利用状況の追跡もありません。

## 知っておきたいこと

- 本格的なアプリを作るには、パソコンのファイルを扱えるツールが必要です。Claude Code（または Claude Desktop の Code タブ）、Codex、Cursor、Gemini CLI、Copilot などです。チャットだけのアプリでも、計画づくりと、クリックして試せる試作品（プロトタイプ）までは作れます。
- お使いの AI ツールの通常のプランや利用上限は、そのまま適用されます。公開後は、サーバー（ホスティング）とドメイン名に月数ドルほどかかるのが一般的です。お金がかかる前には、必ずアシスタントからお知らせします。
- 慎重なアシスタントですが、弁護士や会計士ではありません。支払いや健康に関するデータ、法律で決まりがあることについては、専門家に相談したほうがいいタイミングをお伝えします。
